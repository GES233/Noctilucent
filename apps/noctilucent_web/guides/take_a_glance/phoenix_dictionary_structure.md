下面简单的介绍下 Phoenix 。

Phoenix 属于网络框架，其宗旨是「从原型到生产皆可放心」（Peace of mind from prototype to production）。

网络框架是为了减轻开发网络应用的工作量，将雷同的流程（例如处理客户端的请求、生成 HTML 文件、发送不同类型的 HTTP 响应等）屏蔽起来，让使用者专心编写负责业务逻辑的代码的一类框架。

其官网也写道：

> Build rich, interactive web applications quickly, with less code and fewer moving parts. Join our growing community of developers using Phoenix to craft APIs, HTML5 apps and more, for fun or at scale.

*（使用更少的代码和组件快速构建丰富互动的网络应用。为了乐趣或更大的应用规模，加入我们日益壮大使用 Phoenix 的队伍，搭建你的 API 、 HTML5 App 或更多）*

这一节不讲原理以及实现的细节，主要专注于 Phoenix 项目是什么样子的。

## MVC 模式

Phoenix 是典型的 MVC 的框架，使用同种架构的网络框架也有很多，比方说 RoR 、 Django 等等。

MVC 就是指应用的三类组件：模型（Model）、视窗[^view]（View）以及控制器（Controller）。

[^view]: 不好意思我不知道怎么翻译。
